## Supported Environments

This extension is available for **Google Chrome**, **Microsoft Edge**, and **Firefox**.
To use the extension, you must either set up your own API server or install the necessary dependencies as outlined in the help documentation.
This extension utilizes [yt-dlp](https://github.com/yt-dlp/yt-dlp) as its backend, enabling easy downloads directly from your browser.

## Supported Platforms
Functionality has been verified on the following platforms:

- YouTube
- X
- Instagram
- TikTok
