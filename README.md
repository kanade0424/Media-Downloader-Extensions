## 対応環境

この拡張機能は**Google Chrome**及び**Microsft Edge**、**FireFox**で利用可能です。
また、拡張機能を利用するためには、自分でAPIサーバーを立てるか、ヘルプに沿って必要な依存関係をインストールする必要があります。
この拡張機能では、バックエンドに[yt-dlp](https://github.com/yt-dlp/yt-dlp)を利用しており、ブラウザの拡張機能から簡単にダウンロードできるようにしたものです。

## 対応SNS
以下のプラットフォームでの動作確認をしています。

- YouTube
- X
- Instagram
- TikTok
